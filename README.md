# 地下管网平台

面向城市地下管网运行管理的可视化交互原型，覆盖管网监控、压力与环境监测、漏损预警、安全报告及后台运维配置等场景。纯静态前端，无需构建与依赖安装，数据和图表均为演示用途。

## 功能概览

**运行监测**

| 模块 | 说明 |
| --- | --- |
| 综合驾驶舱 | 关键指标、告警趋势、地图实时监测、告警站点排行与实时告警记录 |
| 管线运行监控 | 管网拓扑展示与测点运行状态 |
| 压力工况监视 | 各测点实时压力曲线与工况明细 |
| 环境参数感知 | 环境类传感数据汇总与趋势 |

**分析与预警**

| 模块 | 说明 |
| --- | --- |
| 噪声异响分析 | 噪声波形与异响识别结果 |
| 漏损预警 | 漏损疑似清单、漏点定位与处置建议 |
| 压力特性分析 | 后台压力特性专项分析 |
| 流量趋势分析 | 后台流量趋势专项分析 |
| 水锤工况分析 | 后台水锤工况专项分析 |

**报告与运维**

| 模块 | 说明 |
| --- | --- |
| 安全运行报告 | 安全指标汇总、报告预览与导出 |
| 台账信息维护 | 设备台账、设备详情与远程管理入口 |
| 告警策略设置 | 告警规则配置 |
| 组织机构维护 | 组织架构与人员管理 |
