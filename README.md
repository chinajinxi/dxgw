# 智慧管网平台 · 地下管网运行管理原型

面向城市地下管网运行管理的可视化交互原型，覆盖管网监控、压力与环境监测、漏损预警、安全报告及后台运维配置等场景。纯静态前端，无需构建与依赖安装，数据和图表均为演示用途。

## 功能概览

**运行监测**

| 模块 | 说明 |
| --- | --- |
| 综合驾驶舱 | 关键指标、告警趋势、地图实时监测、告警站点排行与实时告警记录 |
| 管线运行监控 | 管网拓扑展示与测点运行状态 |
| 压力工况监视 | 各测点实时压力曲线与工况明细 |
| 环境参数感知 | 环境类传感数据汇总与趋势 |

**分析与预警**

| 模块 | 说明 |
| --- | --- |
| 噪声异响分析 | 噪声波形与异响识别结果 |
| 漏损预警 | 漏损疑似清单、漏点定位与处置建议 |
| 压力特性分析 | 后台压力特性专项分析 |
| 流量趋势分析 | 后台流量趋势专项分析 |
| 水锤工况分析 | 后台水锤工况专项分析 |

**报告与运维**

| 模块 | 说明 |
| --- | --- |
| 安全运行报告 | 安全指标汇总、报告预览与导出 |
| 台账信息维护 | 设备台账、设备详情与远程管理入口 |
| 告警策略设置 | 告警规则配置 |
| 组织机构维护 | 组织架构与人员管理 |

## 快速开始

直接用浏览器打开 `index.html` 即可。若需通过本地服务访问：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 技术栈

- 原生 HTML + CSS + JavaScript，无框架、无构建步骤
- 原生 JS 自绘折线图、柱状图、环形图与仪表盘
- 基于 URL Hash 的前端路由，支持刷新与前进后退
- 深色主题大屏布局，适配 1920×1080 演示环境

## 目录结构

```text
.
├── index.html          # 页面入口与静态首屏
├── assets/
│   ├── app.js          # 路由、导航、通用交互
│   ├── pages.js        # 各功能模块页面
│   ├── charts.js       # 图表绘制
│   ├── data.js         # 演示数据
│   └── styles.css      # 主题与布局样式
└── images/             # 界面截图
```

## 交互说明

- 左侧导航切换模块，当前路由同步到地址栏 `#/<模块>`，可直接通过链接定位页面
- 图表支持悬停查看数值；安全指标趋势、告警站点排行支持点击查看对应提示
- 地图测点与告警记录可点击，右侧抽屉展示设备与告警详情
- 安全运行报告支持在预览区导出

## 数据说明

所有指标、曲线、地图测点与名单均由 `assets/data.js` 提供，仅用于界面演示，不代表真实运行数据。接入后端时替换该数据层即可。

## 浏览器支持

推荐使用最新版 Chrome、Edge 或其他 Chromium 内核浏览器。
